1. Ringkasan Eksekutif & Cakupan Mutu

Dokumen Quality Assurance (QA) dan Quality Control (QC) ini disusun sebagai bentuk pertanggungjawaban teknis pengembangan perangkat lunak sistem Radar FMCW. Pengujian mutu dilakukan secara otomatis menggunakan kerangka kerja Pytest untuk memverifikasi fungsionalitas matematis pemrosesan sinyal digital (DSP), integritas arsitektur antrean multi-threading, akurasi kalibrasi daya fisik RF (dBm pada impedansi 50 Ω), serta keandalan penjejakan jarak target.

Akurasi Sinyal & FFT (1.0 kHz/bin)

Resolusi spektrum 1 kHz per bin pada 20 MS/s. Formula daya terkalibrasi ke beban 50 Ohm menghasilkan deviasi daya < 0.1 dBm terhadap nilai analitik.

Peredaman Derau (Savitzky-Golay)

Peredaman fluktuasi derau rumput (noise grass) efektif tanpa mendistorsi frekuensi puncak sinyal pantulan target (error frekuensi ≤ 2 kHz).

Zero Memory Leak (O(1) Ring Buffer)

Riwayat target dikelola menggunakan collections.deque(maxlen=50) dengan kompleksitas O(1) yang menjamin batas alokasi memori tetap konstan selama radar menyapu.

Thread Safety & Non-Blocking UI

Komunikasi antar-thread diisolasi secara aman menggunakan thread-safe FIFO Queue, menjamin antarmuka grafis Dear PyGui beroperasi mulus pada ~60 FPS.
