1. Ringkasan Eksekutif & Cakupan Pengujian Mutu

Laporan QA/QC ini mendokumentasikan hasil pengujian komprehensif terhadap seluruh modul perangkat lunak sistem Radar FMCW Real-Time & Spectrum Analyzer. Pengujian dijalankan secara otomatis menggunakan kerangka kerja Pytest untuk memverifikasi fungsionalitas matematis pemrosesan sinyal digital (DSP), keandalan driver C, mekanisme keamanan ketiadaan hardware (Negative Hardware Tests), integritas antrean multi-threading, akurasi kalibrasi daya RF (dBm pada impedansi 50 Ω), serta stabilitas memori bebas kebocoran (Zero Memory Leak).

Akurasi DSP & FFT (1.0 kHz/bin)

Resolusi spektrum 1 kHz per bin pada 20 MS/s. Formula daya terkalibrasi ke beban 50 Ohm menghasilkan deviasi daya < 0.1 dBm terhadap nilai analitik.

Peredaman Derau (Savitzky-Golay)

Peredaman fluktuasi derau rumput (noise grass) orde-3 terbukti efektif tanpa mendistorsi frekuensi puncak sinyal target (error ≤ 2 kHz).

Zero Memory Leak (O(1) Ring Buffer)

Riwayat target dikelola menggunakan collections.deque(maxlen=50) dengan alokasi memori berbatas tetap (fixed upper bound) dan penambahan O(1).

Keamanan Hardware & Fail-Fast

Sistem membedakan driver DLL dan kartu fisik. Mendukung deteksi hardware riil serta perlindungan fail-fast via check_hardware_or_raise().

3. Metodologi dan Arsitektur Pengujian Sistem

Pengujian dirancang berlapis mencakup pengujian unit (unit tests), pengujian batas domain (boundary & edge cases), pengujian kegagalan hardware (negative hardware tests), pengujian antrean multi-thread, dan pengujian integrasi end-to-end:

  • tests/test_config.py (6 Uji): Verifikasi integritas konstanta laju cuplik 20 MS/s, alokasi buffer 20.000 sampel, batas sudut sapuan (0°–180°), dan palet warna RGBA.

5. Evaluasi Kualitas Perangkat Lunak (Quality Control Criteria)

A. Presisi Matematis & Algoritma DSP

Pada frekuensi sampling 20 MS/s dengan buffer 20.000 sampel, resolusi bin FFT tercapai presisi 1.0 kHz/bin (Δf = fs/N = 20 MHz / 20.000). Formula daya terkalibrasi tepat pada impedansi 50 Ω (P_mW = 10 × V_peak^2).

B. Keandalan Memori & Thread Safety

Struktur data riwayat target menggunakan collections.deque(maxlen=50) menjamin alokasi memori berbatas tetap O(1) tanpa akumulasi tak terbatas (Zero Leak). Antrean thread-safe FIFO mengisolasi antarmuka GUI pada ~60 FPS.

C. Protokol Keamanan Hardware (Fail-Fast)

Sistem membedakan keberadaan pustaka driver DLL dan kartu fisik ADC ADLink PCI-9846H. Metode check_hardware_or_raise() menjamin kegagalan dilaporkan secara eksplisit tanpa menimbulkan freeze.

D. Kemampuan Simulasi Mandiri

Pada komputer tanpa perangkat keras ADC, modul pengujian dan simulasi dapat dieksekusi secara terisolasi untuk memfasilitasi audit kode, QA regresi berkala, dan CI/CD pipeline otomatis.
